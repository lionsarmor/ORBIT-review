ORBIT browser review deployment
This repository contains public browser assets only.
The full ORBIT project remains in its separate private source repository.
Live invitations use the ORBIT droplet helper; messages remain in peer memory.
Your ID, saved invitations and designs persist in encrypted local device storage.
Closing retains saved lounges; Leave removes the selected lounge from this local ID.
A saved code reopens an empty visit when no live members remain.
Lounge options offer a creator wipe or a strict-majority community vote.
Wipes clear live content and activities while retaining the lounge and design.
Web events share one browser hosted on the initiating peer computer.
Hosting needs the local desktop companion; guests receive video and send input.
Browser audio is not streamed; separate embedded pages remain a labelled fallback.
ID backups use a passphrase or a separately downloaded recovery key; no chat or live games are exported.
Phone edition: open phone/ on this site. This is an installable web app, not a native phone package.
Bottom controls hide/restore the entire top bar. Leave lounge is at the bottom of Settings.
Room and private DM files support bounded RAM-only pause/resume.
Streaming sign-in stays on the provider site; readiness is user-confirmed, not account verification.
Development build: not independently security reviewed.
Optional BUDDY/NINA account connectors are disabled on this review site.
